## Platform support (standing caveat)

- **Windows (VST3):** host-tested by the author. Primary supported platform.
- **macOS / Linux (VST3):** CI-built + unit-tested only — not host-tested by
  the author. Please report issues.

## Contents

Each `Abalone-W5-<os>.zip` holds the VST3 bundle + LICENSE + README.
No AU, no installer, no code signing (macOS Gatekeeper may ask for a
right-click Open on first load).
